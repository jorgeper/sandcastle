Conversations: `conversation.start()/open()/send()/list()` give a human a durable, turn-based conversation with an agent running headless in a sandbox — each turn is one resumed iteration of the same agent session, ending in a typed turn envelope (`ask` / `propose` / `done`) extracted as structured output. State lives in `.sandcastle/conversations/<id>/` (metadata + append-only transcript); human messages persist before the agent runs, so a killed process re-attaches with `open()` + `recover()` without losing or double-sending a turn. A reference chat frontend ships on the new `@ai-hero/sandcastle/chat` subpath (Ink terminal UI: transcript with markdown proposals, option select menus, approve/feedback flow, live agent activity; plain-line fallback off-TTY). v1 supports `claudeCode` only — other providers throw the new `ConversationNotSupportedError`. Ships with the `conversational-prd` template: `design.ts` (designer agent grills you into a PRD, opens a PR, then addresses your PR comments through the same conversation) and `decompose.ts` (decomposer agent proposes an issue breakdown and creates Sandcastle-labeled issues after approval). See ADR 0022.
